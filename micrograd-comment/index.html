01 Value 类 — 一切的基础

Value 是 micrograd 的核心，每个 Value 对象存储一个标量值及其梯度， 并通过维护前驱节点构建计算图。

03 反向传播 — backward()

backward() 方法执行两步：1) 拓扑排序构建执行顺序，2) 逆序应用链式法则。

backward 实现

48    def backward(self):


49        # topological order all of the children in the graph


50        topo = []


51        visited = set()


52        def build_topo(v):


53            if v not in visited:


54                visited.add(v)


55                for child in v._prev:


56                    build_topo(child)


57                topo.append(v)


58        build_topo(self)


59


60        # go one variable at a time and apply the chain rule to get its gradient


61        self.grad = 1


62        for v in reversed(topo):


63            v._backward()

05 Neuron — 单神经元

Neuron 实现：y = ReLU(w·x + b)，其中 w 是权重向量，b 是偏置。

nn.py

class Neuron 
13class Neuron(Module):


14    def __init__(self, nin, nonlin=True):


15        self.w = [Value(random.uniform(-1,1)) for _ in range(nin)]


16        self.b = Value(0)


17        self.nonlin = nonlin


18


19    def __call__(self, x):


20        act = sum((wi*xi for wi,xi in zip(self.w, x)), self.b)


21        return act.relu() if self.nonlin else act


22


23    def parameters(self):


24        return self.w + [self.b]

07 MLP — 多层感知机

MLP 由多个 Layer 堆叠而成，除最后一层外都使用 ReLU 激活。

nn.py

class MLP 
39class MLP(Module):


40    def __init__(self, nin, nouts):


41        sz = [nin] + nouts


42        self.layers = [Layer(sz[i], sz[i+1], nonlin=i!=len(nouts)-1)


43                       for i in range(len(nouts))]


44


45    def __call__(self, x):


46        for layer in self.layers:


47            x = layer(x)


48        return x

08 训练流程

使用 micrograd 训练一个简单模型的完整流程： 前向传播 → 计算损失 → 反向传播 → 更新参数。

完整训练循环

1from micrograd.nn import MLP


2


3# 1. 构建模型


4model = MLP(2, [8, 4, 1])


5


6# 2. 前向传播


7x = [1.0, 2.0]


8y_pred = model(x)      # Value(data=?, grad=0)


9


10# 3. 计算损失


11y_true = Value(1.0)


12loss = (y_pred - y_true) ** 2  # MSE


13


14# 4. 反向传播


15loss.backward()


16


17# 5. 更新参数


18lr = 0.1


19for p in model.parameters():


20    p.data -= lr * p.grad


21


22# 6. 清除梯度（下一轮训练）


23model.zero_grad()
